# Information Retrieval - HW1

This project implements and compares different information retrieval models using a document collection. The goal is to build a retrieval system that can index documents and process queries using multiple ranking methods.

## Project Overview

The system consists of two main parts:

1. Document indexing
2. Query processing and retrieval

We implemented and tested different retrieval models and compared their results based on ranking performance.

## Dataset

We use a standard TREC-formatted dataset. Each document in the collection contains an identifier and text content. We parse the data manually because standard XML parsers are not suitable for this format.

Each document includes:
- A document ID field
- A text section containing the main content

We ignore all other parts of the dataset during processing.

## Document Indexing

We read the dataset and process each document one by one. Each document is parsed line by line and stored in a structured format for retrieval.

The main steps in indexing include:
- Reading documents from the collection
- Extracting document IDs
- Extracting text content
- Tokenizing and processing terms
- Building an index structure for retrieval

The index is used by all retrieval models to compute document scores.

## Query Processing

We read queries from a provided query file. Each query is processed against the indexed documents using different retrieval models.

For each query, we retrieve and rank documents based on their relevance scores. We write the top results to output files, with one file per retrieval model.

Each output line follows a standard ranking format including query number, document ID, rank, and score.

## Retrieval Models

We implement the following retrieval models:

- TF-IDF
- Okapi BM25
- Language Model with Laplace smoothing
- Language Model with Jelinek-Mercer smoothing
- Elasticsearch built-in matching query

Each model uses term frequency and document statistics in different ways to compute relevance scores.

## Evaluation

We use trec_eval to evaluate the results. The output files generated by each retrieval model are evaluated against a relevance judgment file.

The evaluation provides standard information retrieval metrics such as precision and recall-based measures.

We also perform a manual comparison of results across different models as part of the analysis.

## Files Included

The project contains scripts for:
- Parsing and indexing the dataset
- Processing queries
- Implementing retrieval models

It also includes result files generated from running the different models.

## Notes

The system was built following the assignment requirements for implementing multiple retrieval models and comparing their performance on the same dataset.
